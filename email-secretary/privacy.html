Email secretary: privacy policy

Last updated 17 October 2026.

What this application is

Email secretary is a private tool used by its author to manage his own Gmail accounts. It is not a service for other people and it has no users other than its author.

What it accesses

With the author's consent through Google sign-in, it uses the Gmail API scope gmail.modify to read messages, add and remove labels, star, archive, move messages to Trash, and create drafts in the author's own mailboxes. It does not use a scope that sends email.

Where data goes

  • Message data is processed on the author's own computers and kept there in a local log.
  • The text of a message may be sent to an AI model provider (Anthropic) to classify it; this is governed by that provider's terms.
  • Links found in a message may be checked against public reputation services (such as Google Safe Browsing). Only the link is sent, never the message.
  • No data is sold, shared with advertisers, or shown to anyone other than the author.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local logs are kept on the author's computers and can be deleted at any time. Access can be revoked at any time from the Google account's third-party access settings, which immediately stops the application.
